# CampusFlow

CampusFlow is a Python command-line helpdesk application for managing
campus technical support tickets.

## Planned features

- Ticket creation and input validation
- Rule-based ticket priority calculation
- Ticket assignment
- Ticket status management
- Ordered work queue
- Reports and summaries
- JSON persistence
- Automated tests using unittest

## Requirements

- Python 3.10 or newer
- Git

## Run the application

Application startup instructions will be added after implementation.

## Run the tests

Once the test suite is implemented, run:

python -m unittest discover -s tests -v
